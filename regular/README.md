# Regular Session (Weekday)

Regent University College, Accra, Ghana

Python examples used in the regular (weekday) class session.

## Topics

| Folder | Topic |
|--------|-------|
| `01_basics/` | Variables, arithmetic, functions, lists, conditionals, dictionaries |
| `02_electronics/` | Voltage divider, Shockley diode equation, NumPy arrays |
| `03_oop/` | Classes, inheritance, polymorphism (+ inheritance lecture plan and slides) |

## How to use

Run any script directly from its folder:

```bash
cd regular/01_basics
python hello_addition.py
```

Each script is self-contained and includes comments explaining what it does.
See the README inside each topic folder for more detail.

## Files in 03_oop

In addition to Python scripts, `03_oop/` contains:

* `inheritance_lecture.md` — a 45-minute lecture plan on Python inheritance
* `python_classes_slides.pptx` — slides for the classes lecture
* `python_inheritance_slides.pptx` — slides for the inheritance lecture
