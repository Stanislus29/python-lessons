# 01_basics — Core Python

Regent University College, Accra, Ghana
Regular session

## What this folder covers

Variables, arithmetic, functions, lists, conditionals, and dictionaries.

## Files

| File | What it does |
|------|--------------|
| `hello_addition.py` | Stores two numbers, adds them, prints the result |
| `simple_functions.py` | Defines `add()` and `multiply()` functions; shows `return` and the `__main__` guard |
| `working_with_lists.py` | Demonstrates `append()`, `insert()`, and `pop()` on a list |
| `conditionals.py` | Loops through numbers and tests a condition with `if` / `break` |
| `dictionaries.py` | Stores capacitors in a dictionary and computes charge `Q = C * V` |
| `component_inventory.py` | List of capacitor dictionaries; computes charge and sorts by charge |

## Lecture material

| File | What it is |
|------|------------|
| `data_structures_lecture.md` | 45-minute lecture plan on lists and dictionaries (objectives, schedule, live-code examples, exercises) |

## How to run

```bash
cd regular/01_basics
python hello_addition.py
```

Try changing the numbers in each script and re-running it to see what
happens.
