A first class in Python: a `Capacitor` that stores capacitance and voltage
and computes its charge.

| File | What it does |
|------|--------------|
| `capacitor_class.py` | A `Capacitor` class with `charge()` computing `Q = C * V` |

## How to run

```bash
cd weekend/02_oop
python capacitor_class.py
```
