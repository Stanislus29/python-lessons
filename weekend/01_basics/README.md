# 01_basics — Core Python (Weekend Session)

Regent University College, Accra, Ghana
Weekend session

## What this folder covers

Reading user input, conditionals, functions, lists, and a basic
electronics calculation.

## Files

| File | What it does |
|------|--------------|
| `hello_addition.py` | Adds two hardcoded numbers and prints the result |
| `arithmetic_with_input.py` | Reads two numbers from the user; prints sum, product, quotient; checks for a factor |
| `adult_or_minor.py` | Reads an age and prints "adult" (18+) or "minor" |
| `capacitor_charge.py` | Computes charge `Q = C * V` for a list of capacitors; flags results above/below 5 |
| `even_numbers.py` | Loops through numbers and reports the even ones |

## How to run

```bash
cd weekend/01_basics
python adult_or_minor.py
```

Scripts that use `input()` will wait for you to type a value and press Enter.
