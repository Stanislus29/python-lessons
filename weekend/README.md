# Weekend Session

Regent University College, Accra, Ghana

Python examples used in the weekend class session.

## Topics

| Folder | Topic |
|--------|-------|
| `01_basics/` | User input, conditionals, charge calculation, even numbers |
| `02_oop/` | A `Capacitor` class (object-oriented programming) |

## How to use

Run any script directly from its folder:

```bash
cd weekend/01_basics
python adult_or_minor.py
```

Each script is self-contained and includes comments explaining what it does.
See the README inside each topic folder for more detail.
