# 03_functions — Reusable Code Blocks

Regent University College, Accra, Ghana

This folder teaches how to define and call functions — reusable blocks of
code that accept inputs, perform work, and return results.

## Concepts covered

* Defining a function with `def`
* Parameters (arguments) and return values
* The `return` statement
* Calling functions with arguments
* The `if __name__ == "__main__":` guard — runs the demo only when the file
  is executed directly, not when imported

## Scripts

| File | What it does |
|------|--------------|
| `simple_functions.py` | Defines `add()` and `multiply()` functions; shows `return` and the `__main__` guard |

## How to run

```bash
cd 03_functions
python simple_functions.py
```
